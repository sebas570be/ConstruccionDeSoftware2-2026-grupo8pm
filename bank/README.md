## Tecnología
- Java 17
- Spring Boot
- Maven
- Lombok

## Descripción
Aplicación de gestión de información bancaria que permite administrar clientes, cuentas, préstamos y transferencias bajo arquitectura DDD (Domain-Driven Design) y patrón hexagonal (Ports & Adapters).

## Cómo ejecutar
1. Clonar el repositorio
2. Entrar a la carpeta `bank`
3. Ejecutar `./mvnw spring-boot:run`
